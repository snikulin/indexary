# Deploy immutable per-user production releases

Indexary's personal production installation uses immutable release directories below `$XDG_DATA_HOME/indexary`, each containing the built application and an exact Node 24 runtime, with an atomic `current` symlink selected by a `systemd --user` service. A manual deployment must pass the local quality gate, smoke-test the candidate on a temporary port, activate it, verify readiness and tailnet access, and automatically restore the previous release on failure; the active release and two predecessors are retained, while application logs go to journald under the existing privacy contract. Tailscale Serve and its owner-only access policy are configured once outside the release lifecycle, and this decision ends the development-only operating phase without creating a distributable release or adding application authentication, automatic updates, zero-downtime deployment, CI, or a separate observability stack.
