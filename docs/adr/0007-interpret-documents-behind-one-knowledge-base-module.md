# Interpret Documents behind one Knowledge Base module

Indexary concentrates filesystem discovery and containment, Document parsing and sanitization, the SQLite index and link graph, material access, diagnostics, and change observation behind one deep Knowledge Base module, while the assembled Fastify application is the external seam used by the web application and integration tests. Each Document is interpreted once on the server into rendered content, searchable text, metadata, resolved links, and diagnostics, avoiding independent browser and server interpretations; coarse revisioned SSE events tell TanStack Query which representations to refresh without exposing the watcher protocol or Document contents. Tests use temporary real filesystem and SQLite adapters, index work remains in-process until a benchmark proves a worker necessary, and no shared workspace package or hypothetical persistence interface is introduced before a second real consumer exists.
