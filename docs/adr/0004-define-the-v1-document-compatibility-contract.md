# Define the v1 document compatibility contract

Indexary v1 treats every non-hidden `.md` file inside the canonical Knowledge Base root as a Document and renders CommonMark with GFM extensions, YAML frontmatter, and wikilinks without executing unsanitized HTML or automatically loading remote embeds. The `title`, `tags`, and `originals` fields have application semantics, while `original_path` remains a supported legacy spelling and other valid YAML fields remain visible as generic properties; a Document title is selected from frontmatter `title`, then its first H1, then its filename. Source Material paths in frontmatter resolve from the Knowledge Base root, Attachment paths in Markdown resolve from the containing Document, every resolved path must remain inside the canonical root, ambiguous wikilinks are never resolved arbitrarily, and a malformed or unreadable file is isolated with a content-safe diagnostic rather than preventing access to the rest of the Knowledge Base.
