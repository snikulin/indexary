# Run Indexary beside its Knowledge Base

When Indexary is eventually deployed, its target topology is the user-controlled machine that holds its Knowledge Base, reading that directory directly. The initial development phase has no separate production installation: an explicit development mode supplies the personal Knowledge Base path from the current checkout. The path is runtime configuration—`~/vault` is one user's value, not a project default—and one process serves one Knowledge Base. Symbolic links are followed only when their canonical targets remain inside that root; external or cyclic links are skipped with a warning. The server binds to localhost by default; remote access is delegated to Tailscale rather than introducing data synchronization or public exposure into Indexary.
